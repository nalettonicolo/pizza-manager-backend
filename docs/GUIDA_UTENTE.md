# Guida utente finale

Il contenuto mostrato in **Admin → Guida** nell’applicazione è il file:

**`src/content/guidaUtente.md`**

Per aggiornare la guida online: modifica quel file, esegui build e deploy del frontend (`npm run deploy` o la pipeline abituale).

Per una panoramica piattaforma (super admin) resta disponibile `docs/GUIDA_SUPERADMIN.md`.
